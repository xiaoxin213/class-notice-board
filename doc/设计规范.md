# 设计规范：暖黄风格

> v0.1　　2026-09-07
> 色值由脚本从参考截图逐像素采样得出（过滤掉截图上的红色批注文字和 Chrome 自动填充的淡蓝底色）。

---

## 1. 基调

暖黄 / 琥珀色系，低饱和背景 + 高饱和品牌色点缀。整体偏"温和、校园、非科技感"——这个方向是对的，用户是老师不是工程师，界面越像消费级工具越好上手。

主色相集中在 **30°~45°**（橙到琥珀），饱和度接近 100%，明度 0.88~0.97。背景是同色相的极低饱和版本，所以整个页面是"同一束暖光"下的效果，而不是白底加彩色控件。

## 2. 色板

### 品牌色

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--brand-400` | `#F8B000` | 渐变亮端、图标高光 |
| `--brand-500` | `#F5A623` | 品牌主色、铃铛图标、选中态 |
| `--brand-600` | `#E88000` | 渐变暗端、按钮 hover |
| `--brand-700` | `#E07800` | 按下态、强调文字 |

主按钮（登录 / 立即发布）用渐变：

```css
background: linear-gradient(90deg, var(--brand-400), var(--brand-600));
```

### 背景与表面

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--bg-page` | `#FFF8ED` | 页面底色，最外层的暖黄 |
| `--bg-surface` | `#FFFFFF` | 卡片、主内容区 |
| `--bg-surface-warm` | `#FEFCF6` | 次级卡片（登录卡、预览卡） |
| `--bg-subtle` | `#FBF8EE` | 分区块、表单区底色 |
| `--bg-brand-weak` | `#FEF8E6` | 选中项底色、标签底色 |

### 描边与文字

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--border` | `#F0E6D2` | 卡片与输入框描边（暖调，不要用灰） |
| `--border-strong` | `#E8D8B8` | 强调边框、选中态描边 |
| `--text-primary` | `#333333` | 正文 |
| `--text-secondary` | `#666666` | 辅助说明 |
| `--text-tertiary` | `#999999` | 占位符、时间戳 |

> ⚠️ 描边一律走暖调米色，**不要用 `#E5E5E5` 这类中性灰**。混进冷灰会立刻破坏"同一束暖光"的整体感，这是这套风格最容易翻车的地方。

### 状态色

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--success` | `#12B76A` | 在线、已连接、语音已开启 |
| `--danger` | `#E04B4B` | 离线、错误、危险操作 |
| `--info` | `#666666` | 中性状态 |

在线/离线用小圆点 + 文字，不要只用颜色区分——教室里的投影和老旧显示器色彩还原很差。

## 3. 圆角与阴影

| Token | 值 |
| --- | --- |
| `--radius-sm` | `6px`（输入框、小标签） |
| `--radius-md` | `10px`（按钮、模板胶囊） |
| `--radius-lg` | `16px`（卡片、面板） |
| `--shadow-card` | `0 2px 12px rgba(200, 150, 60, 0.08)` |

阴影用**暖色投影**而不是黑色投影，这是暖色系界面显得干净的关键。

## 4. 字体

```css
font-family: "PingFang SC", "Microsoft YaHei", "Hiragino Sans GB", sans-serif;
```

Win7 教室机没有苹方，微软雅黑是保底。

| 场景 | 字号 / 字重 |
| --- | --- |
| 页面标题 | 20px / 600 |
| 区块标题 | 15px / 600 |
| 正文 | 14px / 400 |
| 辅助说明 | 12px / 400 |

### 教室大屏正文

**单独一套规则，和管理端无关。** 教室屏的唯一任务是让最后一排看清：

- 字号用视口单位，不用固定 px：`font-size: clamp(48px, 9vw, 160px)`
- 字重 700，行高 1.4，居中，左右各留 8% 边距
- 内容超长时自动降档，但设下限——宁可截断也不能小到看不清
- 深色底浅色字 or 浅底深字二选一，别用暖黄底配橙字，投影仪上对比度会不够

## 5. 移动端（H5）适配要点

- 断点 `768px`，以下切单栏
- 三栏工作台在手机上只保留发布主干；班级管理、教室绑定收进二级页
- 主按钮固定在底部安全区内，拇指可达
- 常用模板做成横向可滑动的胶囊，不换行堆叠
- 输入框字号 ≥ 16px，否则 iOS Safari 聚焦时会自动放大页面

## 6. 采样方法备查

```
筛选 saturation > 0.35 且 value > 0.35 的像素，按 8 位量化后统计词频。
排除项：#C83838 系（截图上的红色批注文字）、#E8EFFD（Chrome 密码自动填充底色）。
绿色样本量少（仅状态点和小字），色值为近似值，实装时可微调。
```
