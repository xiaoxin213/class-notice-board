# 开发指南

> 记录开发过程中踩过的坑和需要注意的约定，防止下次重复犯错。
> 整理日期：2026-09-08

---

## 1. 文件提交工具的路径规则（device_commit_files）

**坑**：`device_commit_files` 的 `stagedPath` 参数**必须**是 `/mnt/user-data/outputs/` 下的路径，`/home/claude/` 或 `/tmp/` 下的路径会被拒绝。

**正确流程**：
```bash
# ❌ 错误：直接用 /home/claude/ 的路径
device_commit_files([{ stagedPath: "/home/claude/xxx.md", devicePath: "F:\\..." }])

# ✅ 正确：先复制到 outputs 目录，再提交
cp /home/claude/xxx.md /mnt/user-data/outputs/xxx.md
device_commit_files([{ stagedPath: "/mnt/user-data/outputs/xxx.md", devicePath: "F:\\..." }])
```

类似地，`device_stage_files` 暂存的路径（`/mnt/user-data/uploads/...`）是只读快照，**不能**用作 `device_commit_files` 的 `stagedPath`。

## 2. 跨平台构建限制：macOS DMG 不能在 Windows 上构建

electron-builder 无法跨平台构建：Windows 机器**无法**生成 macOS 的 `.dmg` 文件。

**解决方案**：在 GitHub Actions 上分开两个 workflow：
- `build-win.yml`：在 `windows-latest` runner 上构建 NSIS 安装包
- `build-mac.yml`：在 `macos-latest` runner 上构建 DMG（x64 + arm64），手动触发

本地开发时：
- Windows：`npm run build`（生成 .exe）
- macOS：`npm run build:mac`（生成 .dmg）
- 不要尝试在 Windows 上执行 `build:mac`

## 3. React Router SPA 路由需要 BrowserRouter 包裹

项目使用 react-router-dom v7，必须在最外层用 `BrowserRouter`（或等价的路由上下文）包裹，否则 `Routes` / `useNavigate` 会报错。

```tsx
// web/src/main.tsx
import { BrowserRouter } from 'react-router-dom'

createRoot(document.getElementById('root')!).render(
  <StrictMode>
    <BrowserRouter>
      <App />
    </BrowserRouter>
  </StrictMode>
)
```

`App.tsx` 只做路由表，不需要再套 `BrowserRouter`。

## 4. 落地页 CSS 与工作台 CSS 的隔离

工作台的 `global.css` 在 `html, body` 上设置了 `overflow: hidden`（因为工作台是固定高度面板，不需要页面滚动）。落地页需要正常滚动，如果共用这套样式，落地页会无法滚动。

**解决方案**：落地页所有样式放在 `LandingPage.css` 中，用 `.landing-root` 类名作用域隔离：

```css
/* LandingPage.css */
.landing-root {
  position: fixed;
  inset: 0;
  overflow-y: auto;
  overflow-x: hidden;
  /* 落地页自己的背景、字体等 */
}
```

落地页的所有元素都包在 `<div className="landing-root">` 内，工作台的全局 `overflow: hidden` 不会影响到它。

同样，落地页的 CSS 变量名加 `--l` 前缀（`--lbrand`、`--lbg` 等），避免与工作台的 `--brand`、`--bg` 等变量冲突。

## 5. Google Fonts 必须在 index.html 中引入

在组件的 `.css` 文件里 `@import url('https://fonts.googleapis.com/...')` 有时在 Vite 构建后不生效（CSP 或加载顺序问题）。

**正确做法**：在 `web/index.html` 的 `<head>` 中直接用 `<link>` 引入：

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Noto+Serif+SC:wght@400;700&family=Inter:wght@400;500;600&display=swap" rel="stylesheet">
```

## 6. 服务端已内建 SPA 回退，无需额外配置 nginx try_files

服务端的 `setNotFoundHandler` 已处理 SPA 回退：对非 `/api`、非 `/ws` 的路径，统一返回 `index.html`。

因此直接访问 `https://你的域名/console` 也会正确加载 React 应用。**不需要**在 nginx 配置 `try_files $uri $uri/ /index.html`。

但 nginx 的 **WebSocket 升级头**和 **SSE 长连接**配置是必须的，见 `部署说明.md §4`。

## 7. 注册逻辑：inviteCode 为空等于关闭注册

服务端注册接口的检查逻辑是：

```js
const currentCode = getSetting(db, 'invite_code', config.inviteCode)
if (!currentCode || inviteCode !== currentCode) {
  return reply.code(403).send({ error: '注册需要邀请码，请联系管理员获取' })
}
```

所以：
- `INVITE_CODE` 环境变量不设置 → `currentCode` 为空字符串 → `!currentCode` 为 `true` → **注册完全关闭**
- 想开放注册，必须设置一个非空的邀请码

公网部署**务必**设置 `INVITE_CODE`，否则任何人无法注册（包括自己）。

## 8. 管理员身份是用户名匹配，不是独立账号类型

```js
const isAdmin = row.username === config.adminUsername
```

- `ADMIN_USERNAME` 环境变量定义哪个用户名是管理员（默认 `admin`）
- 管理员同时保留完整的班主任权限
- 必须先注册该用户名的账号，再配置 `ADMIN_USERNAME`；或者用 `INIT_ADMIN_USERNAME` + `INIT_ADMIN_PASSWORD` 让服务端启动时自动创建

## 9. Electron 构建：package.json 需要同时有 scripts 和 build 两个部分

`npm run build:mac` 报 "Missing script" 的原因：`classroom/package.json` 的 `scripts` 字段没有 `build:mac`，且 `build` 字段没有 `mac` / `dmg` 段。两者缺一不可：

```json
{
  "scripts": {
    "build:mac": "electron-builder --mac --x64 --arm64"
  },
  "build": {
    "mac": {
      "target": [{ "target": "dmg", "arch": ["x64", "arm64"] }],
      "icon": "assets/icon.png",
      "category": "public.app-category.education"
    },
    "dmg": {
      "title": "${productName} ${version}"
    }
  }
}
```

## 10. WebSocket 断线重连必须加随机抖动

教室端重连逻辑要加 `±20%` 随机抖动：

```js
const jitter = 0.8 + Math.random() * 0.4   // 0.8 ~ 1.2
setTimeout(connect, delay * jitter)
delay = Math.min(delay * 2, 30000)
```

不加抖动时，全校所有教室电脑会在网络恢复的同一时刻同时发起 WebSocket 连接，形成"惊群效应"，可能打垮服务端。

## 11. SQLite 备份不能直接 cp，需要 VACUUM INTO

SQLite 开了 WAL 模式，直接 `cp` 文件会得到不一致的快照。正确的备份方式：

```bash
docker compose exec class-notice-board \
  node --input-type=module -e "
import { DatabaseSync } from 'node:sqlite';
const db = new DatabaseSync('/data/data.db');
db.exec(\"VACUUM INTO '/data/backup.db'\");
db.close();
"
```

## 12. `.github/` 目录在远程设备工具中是写保护的

在用 `device_commit_files` 提交文件时，`.github/` 目录下的文件会报 "Permission denied"。

**解决方案**：通过 git 命令直接修改 `.github/` 下的文件，或手动在本地修改后提交。不要尝试用 `device_commit_files` 写入该目录。
