# 接口文档

> 对应 `server/` 当前版本。所有请求与响应均为 JSON，UTF-8。
> 教师接口用 `Authorization: Bearer <token>`；教室端用设备令牌走 WebSocket。

---

## 约定

- 时间戳统一为**秒级** Unix 时间（`last_seen_at` 等字段）
- 出错时返回 `{ "error": "中文提示" }`，文案可直接展示给老师
- 状态码：400 参数错误 / 401 未登录 / 403 无权限 / 404 不存在 / 409 冲突 / 429 限流 / 500 服务异常

## 账号

### POST /api/auth/register

注册教师账号，需要邀请码（invite_code 为空时注册完全关闭）。

```jsonc
// 请求
{ "username": "chenfeifei", "password": "pass1234", "displayName": "陈老师", "inviteCode": "SCHOOL2026" }
// 201
{ "token": "...", "teacher": { "id": 1, "username": "chenfeifei", "displayName": "陈老师", "isAdmin": false } }
```

约束：账号名 ≥ 3 字符，密码 ≥ 6 位，账号名全局唯一（冲突返回 409）。

### POST /api/auth/login

```jsonc
// 请求
{ "username": "chenfeifei", "password": "pass1234" }
// 200
{ "token": "...", "teacher": { "id": 1, "username": "chenfeifei", "displayName": "陈老师", "isAdmin": false } }
```

账号被停用返回 403。`isAdmin` 表示该账号是否为管理员（用户名匹配 `ADMIN_USERNAME` 环境变量）。

### GET /api/me

返回当前登录教师信息。需要 Bearer token。

```jsonc
// 200
{ "id": 1, "username": "chenfeifei", "displayName": "陈老师", "isAdmin": false }
```

## 班级

### GET /api/classes

获取当前教师的班级列表。

```jsonc
// 200
{
  "max": 50,
  "classes": [
    { "id": 1, "name": "五(1)班", "role": "owner", "online": 1 },
    { "id": 2, "name": "三年二班", "role": "assistant", "online": 0 }
  ]
}
```

`role`：`owner` 班主任 / `assistant` 兼任。`online` 是该班级当前在线的教室端台数（实时进程内存，不落库）。

### POST /api/classes

创建班级。

```jsonc
// 请求
{ "name": "五(1)班" }
// 201
{ "id": 1, "name": "五(1)班", "role": "owner", "online": 0 }
```

超过配额（默认 50 个）返回 400。

### PATCH /api/classes/:id

修改班级名称。只有 `owner`（班主任）可以操作。

```jsonc
// 请求
{ "name": "五(2)班" }
// 200
{ "id": 1, "name": "五(2)班" }
```

### DELETE /api/classes/:id

删除班级（级联删除设备、通知等记录）。只有 `owner` 可以操作。

```
// 204 No Content
```

## 教室绑定

### POST /api/classes/:id/bind-code

为指定班级生成 6 位数字绑定码，默认有效期 30 分钟（`BIND_CODE_TTL_SECONDS` 可改）。

```jsonc
// 201
{ "code": "832813", "expireAt": 1757224113 }
```

同一班级可多次生成，新码覆盖旧码。

### POST /api/device/bind

**无需登录**，教室端客户端调用完成绑定。

```jsonc
// 请求
{ "code": "832813", "deviceName": "五一班教室机" }
// 201
{ "deviceToken": "dt_xxxxxxxx...", "deviceId": 3, "classId": 1, "className": "五(1)班" }
```

- 绑定码用后立即作废
- `deviceToken` 是长期凭据，教室端落盘保存，后续 WebSocket 连接用它认证
- 同一班级内同名设备重复绑定时复用旧记录（换机器不堆积设备）
- **限流**：同一 IP 10 分钟内失败 10 次返回 429；绑定码只有 6 位数字（100 万种），此限制不可省

### GET /api/classes/:id/devices

获取班级下的设备列表。

```jsonc
// 200
{ "devices": [ { "id": 3, "name": "五一班教室机", "last_seen_at": 1757222400, "online": true } ] }
```

### DELETE /api/classes/:id/devices/:deviceId

删除设备记录。**设备在线时不允许删除**（返回 400）。

```
// 204 No Content
```

### POST /api/classes/:id/sound-test

向该班级在线教室端发送声音测试指令（播一句"声音测试，教室电脑已就绪。"）。

```jsonc
// 200
{ "sentTo": 1 }   // 发出的台数
```

## 通知

### POST /api/notices

发布通知。

```jsonc
// 请求
{ "classId": 1, "content": "请全班同学马上到操场集合。", "displaySeconds": 60, "speakTimes": 2 }
// 201
{ "id": 12, "sentTo": 1, "online": 1 }
```

- `content`：非空，≤ 200 字（`MAX_NOTICE_LENGTH` 可改）
- `displaySeconds`：大屏显示秒数，收敛到 5～3600，默认 60
- `speakTimes`：语音播报次数，收敛到 0～10，默认 2
- `sentTo`：**发出台数，不是确认收到台数**；送达确认走 SSE 的 `notice_ack` 事件
- 无设备在线时也返回 201（`sentTo: 0`），设备在 TTL 内上线后补投一次

### GET /api/notices?classId=1

获取该班级最近 30 条通知记录。

```jsonc
// 200
{
  "notices": [
    {
      "id": 12,
      "content": "请全班同学马上到操场集合。",
      "status": "delivered",
      "created_at": 1757222400,
      "display_seconds": 60,
      "speak_times": 2,
      "publisher": "陈老师"
    }
  ]
}
```

`status`：`pending` 待送达 / `delivered` 已全部送达 / `expired` 超时作废（TTL 默认 5 分钟）。

## 管理后台（需管理员权限）

以下接口同时需要 `requireTeacher` + `requireAdmin` 双重验证。管理员身份由 `ADMIN_USERNAME` 环境变量定义。

### GET /api/admin/stats

获取所有用户及其使用统计。

```jsonc
// 200
{
  "teachers": [
    {
      "id": 1, "username": "admin", "displayName": "管理员",
      "disabled": false, "createdAt": 1757000000,
      "classCount": 2, "deviceCount": 3, "onlineCount": 1
    }
  ],
  "totalOnline": 5
}
```

### GET /api/admin/settings

获取注册设置。

```jsonc
// 200
{ "inviteCode": "SCHOOL2026" }
```

### PUT /api/admin/settings

修改注册邀请码。空字符串表示关闭注册。修改立即生效。

```jsonc
// 请求
{ "inviteCode": "NEW_CODE_2027" }
// 200
{ "inviteCode": "NEW_CODE_2027" }
```

### GET /api/admin/downloads

列出可供下载的教室端安装包（扫描 `WEB_ROOT/downloads/` 下的 `.exe`、`.dmg`、`.pkg` 文件）。

```jsonc
// 200
{ "files": [ { "name": "ClassNoticeBoard-v1.0.0-win.exe", "url": "/downloads/ClassNoticeBoard-v1.0.0-win.exe" } ] }
```

### PATCH /api/admin/teachers/:id

修改指定用户的姓名或密码。

```jsonc
// 请求（字段均可选）
{ "displayName": "张老师", "password": "newPass123" }
// 200
{ "ok": true }
```

### PATCH /api/admin/teachers/:id/disabled

停用或启用指定用户（管理员账号不能被停用）。

```jsonc
// 请求
{ "disabled": true }
// 200
{ "ok": true, "disabled": true }
```

### DELETE /api/admin/teachers/:id

删除指定用户（管理员账号不能被删除）。

```
// 204 No Content
```

## 教师端事件流（SSE）

### GET /api/events?token=\<token\>

长连接 SSE。因为 `EventSource` 无法自定义请求头，令牌走 query 参数。

连接成功后服务端推送两类事件：

```
data: {"type":"device_status","classId":1,"online":1}

data: {"type":"notice_ack","noticeId":12,"classId":1,"deviceId":3,"allDelivered":true}
```

每 20 秒发一个 `: ping` 注释行保活。`X-Accel-Buffering: no` 响应头防止 nginx 缓冲。

## 教室端 WebSocket

### GET /ws/device?token=\<deviceToken\>

令牌无效直接返回 HTTP 401 拒绝握手。

**服务端 → 教室端**

```jsonc
// 连接建立后立即推送
{ "type": "ready", "deviceId": 3, "classId": 1, "className": "五(1)班" }

// 有新通知时
{ "type": "notice", "id": 12, "content": "请全班同学马上到操场集合。",
  "publisher": "陈老师", "publishedAt": 1757222400,
  "displaySeconds": 60, "speakTimes": 2, "expireAt": 1757222700 }

// 声音测试
{ "type": "sound_test", "text": "声音测试，教室电脑已就绪。" }

// 心跳（服务端主动发，25 秒一次）
{ "type": "ping", "ts": 1757222400000 }
```

**教室端 → 服务端**

```jsonc
{ "type": "ack", "id": 12, "status": "displayed" }   // 展示后立即回执
{ "type": "ping", "ts": 1757222400000 }              // 服务端回 { "type": "pong", "ts": ... }
```

### 客户端实现要点

1. **收到任何帧都算心跳活着**，服务端据此刷新最后在线时间
2. 服务端每 25 秒下发 `ping`，超过 60 秒没收到任何消息判定离线
3. 断线后**指数退避重连**：1s → 2s → 4s … 封顶 30s，**必须加 ±20% 随机抖动**，否则全校设备同时冲击服务端
4. 按 `notice.id` 去重，补投逻辑可能导致同一条通知重复到达
5. `expireAt` 已过的通知直接丢弃，不展示不播报
