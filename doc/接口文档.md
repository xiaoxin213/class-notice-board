# 接口文档

> 对应 `server/` v0.1。所有请求与响应均为 JSON，UTF-8。
> 教师接口用 `Authorization: Bearer <token>`；教室端用设备令牌走 WebSocket。

---

## 约定

- 时间戳统一为**秒级** Unix 时间
- 出错时返回 `{ "error": "中文提示" }`，文案可直接展示给老师
- 状态码：400 参数错误 / 401 未登录 / 403 无权限 / 409 冲突 / 429 限流

## 账号

### POST /api/auth/register

```jsonc
// 请求
{ "username": "chenfeifei", "password": "pass1234", "displayName": "陈老师", "inviteCode": "SCHOOL2026" }
// 201
{ "token": "...", "teacher": { "id": 1, "username": "chenfeifei", "displayName": "陈老师" } }
```

账号名 ≥ 3 字符，密码 ≥ 6 位。服务端设了 `INVITE_CODE` 时邀请码必填且必须匹配。

### POST /api/auth/login

```jsonc
{ "username": "chenfeifei", "password": "pass1234" }
// 200 同上结构
```

### GET /api/me

返回 `{ id, username, displayName }`。

## 班级

### GET /api/classes

```jsonc
{
  "max": 50,
  "classes": [ { "id": 1, "name": "五(1)班", "role": "owner", "online": 1 } ]
}
```

`role`：`owner` 班主任 / `assistant` 兼任。`online` 是该班级当前在线的教室端台数。

### POST /api/classes

```jsonc
{ "name": "五(1)班" }
// 201 { "id": 1, "name": "五(1)班", "role": "owner", "online": 0 }
```

超过 `max` 返回 400。

## 教室绑定

### POST /api/classes/:id/bind-code

生成 6 位数字绑定码，默认 30 分钟过期。

```jsonc
// 201
{ "code": "832813", "expireAt": 1757224113 }
```

### POST /api/device/bind

**无需登录**，教室端调用。

```jsonc
{ "code": "832813", "deviceName": "五一班教室机" }
// 201
{ "deviceToken": "...", "deviceId": 3, "classId": 1, "className": "五(1)班" }
```

绑定码用后立即作废。`deviceToken` 是长期凭据，教室端要落盘保存，后续连接都用它。

**限流**：同一 IP 10 分钟内失败 10 次返回 429。绑定码只有 6 位数字、100 万种组合，这个限制不能省。

### GET /api/classes/:id/devices

```jsonc
{ "devices": [ { "id": 3, "name": "五一班教室机", "last_seen_at": 1757222400, "online": true } ] }
```

### POST /api/classes/:id/sound-test

让该班级在线教室端播一句测试语音，用来确认音箱开着、音量正常。

```jsonc
// 200 { "sentTo": 1 }
```

## 通知

### POST /api/notices

```jsonc
{ "classId": 1, "content": "请全班同学马上到操场集合。", "displaySeconds": 60, "speakTimes": 2 }
// 201
{ "id": 12, "sentTo": 1, "online": 1 }
```

- `content` 非空、≤ 200 字
- `displaySeconds` 取值收敛到 5~3600，默认 60
- `speakTimes` 取值收敛到 0~10，默认 2
- `sentTo` 是**发出的台数，不是确认收到的台数**。送达确认走 SSE 的 `notice_ack` 事件
- 无设备在线时也会成功创建（`sentTo: 0`），设备上线后在 TTL 内补投一次

### GET /api/notices?classId=1

返回最近 30 条：

```jsonc
{ "notices": [ { "id": 12, "content": "...", "status": "delivered", "created_at": 1757222400,
                 "display_seconds": 60, "speak_times": 2, "publisher": "陈老师" } ] }
```

`status`：`pending` 待送达 / `delivered` 已全部送达 / `expired` 超时作废。

## 教师端事件流

### GET /api/events?token=\<token\>

SSE。EventSource 无法自定义请求头，所以令牌走 query。

```
data: {"type":"device_status","classId":1,"online":1}

data: {"type":"notice_ack","noticeId":12,"classId":1,"deviceId":3,"allDelivered":true}
```

每 20 秒发一个 `: ping` 注释行保活。

## 教室端 WebSocket

### GET /ws/device?token=\<deviceToken\>

令牌无效直接返回 401 拒绝握手。

**服务端 → 教室端**

```jsonc
{ "type": "ready", "deviceId": 3, "classId": 1, "className": "五(1)班" }

{ "type": "notice", "id": 12, "content": "请全班同学马上到操场集合。",
  "publisher": "陈老师", "publishedAt": 1757222400,
  "displaySeconds": 60, "speakTimes": 2, "expireAt": 1757222700 }

{ "type": "sound_test", "text": "声音测试，教室电脑已就绪。" }

{ "type": "ping", "ts": 1757222400000 }
```

**教室端 → 服务端**

```jsonc
{ "type": "ack", "id": 12, "status": "displayed" }   // 展示后立即回执
{ "type": "ping", "ts": 1757222400000 }              // 服务端回 pong
```

### 客户端实现要点

1. **收到任何帧都算活着**，服务端据此刷新最后在线时间
2. 服务端每 25 秒下发 `ping`，超过 60 秒没收到任何消息就判离线
3. 断线后指数退避重连：1s → 2s → 4s … 封顶 30s，**必须加 ±20% 随机抖动**，否则网络恢复时全校设备会同时冲击服务端
4. 按 `notice.id` 去重，补投逻辑可能让同一条通知重复到达
5. `expireAt` 已过的通知直接丢弃，不展示不播报
